# Task 1: E-Commerce Dataset Cleaning

## Project Overview
This project focuses on cleaning and preparing an e-commerce dataset for further analysis. The main objective is to improve data quality by identifying missing values, duplicate records, inconsistent formats, and invalid data.

## Objectives
- Inspect the dataset and understand its structure.
- Identify and handle missing values.
- Detect and investigate duplicate records.
- Check data types and validate important fields.
- Standardize inconsistent values where required.
- Save the cleaned dataset separately from the raw data.
- Document the cleaning process and decisions.

## Tools and Technologies
- Python
- Pandas
- Google Colab
- Jupyter Notebook

## Workflow
1. Load and inspect the raw dataset.
2. Examine columns, data types, and missing values.
3. Check for duplicate records.
4. Perform data validation and cleaning.
5. Review the cleaned data.
6. Save the cleaned dataset and cleaning-related outputs.

## Expected Deliverables
- Data cleaning notebook
- Cleaned dataset
- Missing-value and duplicate analysis
- Validation checks
- Cleaning summary and explanation of decisions

## Outcome
The task produces a cleaned and organized dataset that can be used for sales analysis and visualization in the next tasks.

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Make sure the required dataset is available.
3. Run the notebook cells in order.
